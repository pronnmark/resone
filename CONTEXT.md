# Context — the studio's vocabulary

Terms as the studio uses them. Do not translate or "correct" them (`AGENTS.md`, rule 4).

| Term | Meaning |
|---|---|
| **Résone** | The studio. Wordplay on *résonner* (to resound) and *raisonner* (to reason). Tagline: *l'art de faire résonner*. |
| **les sœurs Ré** | Omara Ré and Inès Ré, the two founders. |
| **quatre-mains** | Work done by two pairs of hands, the sisters together. Their working method and a line in their manifesto. |
| **grain de beauté** | The beauty mark above the lip. The studio's signature, embroidered discreetly on pieces. The site's only motif. |
| **œuvre / artwork** | Every piece is an artwork. Each artwork belongs to one style. There are no collections. |
| **style** | One of the three signature families: ombres chinoises, HANOKA, patchwork. Each new style is registered with the international IP office. |
| **ombres chinoises** | Chinese shadow technique: cloth pieces made to be lit from behind. *Ivresse écarlate*, *Apprentis Sages*, *Accords vitaminés*. |
| **HANOKA** | A textile wall installation inspired by the Korean *hanok* (traditional house), from Bukchon, Seoul. |
| **patchwork** | Recycled denim cut and reassembled into mosaics and garments. *L'architecture de l'eau* has 282 hand-numbered pieces. |
| **patchwork signature** | The studio's name for its garment line (*vêtement*). |
| **le tablier de l'artisan** | The artisan's apron. A made-to-measure piece honouring craft, one version made for a wine house. |
| **créton / crétonne** | A heavy cotton fabric used in the pieces. |
| **popeline** | Poplin, a fine cotton. |
| **tissu « sky »** | A fabric the deck names in the materials of several pieces. Left as the studio writes it. |
| **masterpiece** | The studio's word for *Ivresse écarlate*, which opens the portfolio. Inferred from the memos; not yet confirmed. |
| **sur demande** | On request. What a piece says instead of a price. |
| **Créative Côte d'Ivoire** | The Ministry of Culture programme that incubated Résone in 2026. |
| **atelier** | The studio's workspace in Riviera 3, Abidjan, also its exhibition space. Renamed *workshop* in the memos; the site keeps *Atelier*. |

## Site terms

| Term | Meaning |
|---|---|
| **mosaic** | The justified image grid that every page is built from. |
| **tile** | One image in the mosaic; a `<button>` that opens the lightbox. |
| **group** | A style section on the portfolio (`.works` with a label). |
| **filter row** | The Tout / style buttons above the portfolio. |
| **lightbox** | The full-size view of a piece, with previous/next and an inquiry link. |
