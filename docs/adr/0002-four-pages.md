# 0002 — Four pages

Date: 2026-09-28. Status: accepted.

**Context.** The site had six pages. In the memos the studio asked to land on the portfolio,
fold installations into the atelier, and keep redundancy low.

**Decision.** Portfolio (landing), Atelier, À propos, Contact. Each page is header, mosaic,
footer, and nothing else (`AGENTS.md`, rule 0). The retired URLs redirect to `/`.

**Consequences.** New content goes in a caption, a card or the footer, never a new section.
The About page is a card in a mosaic row because a text section is what the studio killed.

**Amendment 2026-09-30.** The landing page is now one continuous scroll for phones: the
style groups, then Atelier, À propos and Contact as further `.works` sections. The nav links
are anchors (`#works`, `#atelier`, `#apropos`, `#contact`). The separate pages still exist and
carry the same content. Rule 0 still holds (0 sections that are not `.works`).
